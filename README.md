# سیستەمی تاقیکردنەوەی OMR (Kurdish Sorani OMR Examination Platform)

پلاتفۆرمێکی فەرمی و تەواو بەرهەمهێنراو بە زمانی کوردی سۆرانی (RTL) بۆ بەڕێوەبردن، بەرهەمهێنان، سکانکردن و خوێندنەوەی پەڕەی وەڵامی تاقیکردنەوەکان (OMR) بە بەکارهێنانی بینایی کۆمپیوتەر (Computer Vision) و فێربوونی ئامێر.

---

## تایبەتمەندییە سەرەکییەکان (Core Features)

1. **داشبۆردی سەرەکی (Dashboard)**
   - ئاماری ڕاستەوخۆ (ژمارەی قوتابیان، تاقیکردنەوەکان، پەڕە خوێندراوەکانی ئەمڕۆ، چاوەڕوانی پێداچوونەوە، تێکڕای نمرەکان).
   - دوگمەی خێرای سکانکردن و چاپکردنی پەڕە.

2. **بەڕێوەبردنی تاقیکردنەوەکان (Exam Management)**
   - دروستکردن، دەستکاریکردن، کۆپیکردن (Duplicate) و سڕینەوە بە دڵنیابوونەوە.
   - دیاریکردنی ژمارەی پرسیارەکان (٢٠، ٢٥، ٣٠، ٤٠، ٥٠، ٦٠، ٨٠، ١٠٠ پرسیار).
   - هەڵبژاردەی (A-D) یان (A-E).

3. **دروستکەری کلیلی وەڵام (Interactive Answer Key Builder)**
   - دیاریکردنی وەڵامی دروست بە کرتەکردن لەسەر بازنەکان.
   - دیاریکردنی نمرەی پرسیار و پرسیاری بەخشش (Ungraded).

4. **بەرهەمهێنەری پەڕەی وەڵامی ستاندارد (A4 OMR Sheet Generator)**
   - ئەندازەی فیزیکی ستاندارد A4 (210 × 297 mm) بە ٤ نیشانەی چوارگۆشەی گۆشەکان (Registration Markers).
   - کۆدی QR بۆ ناسینەوەی تاقیکردنەوە و قوتابی بە ئۆتۆماتیکی.
   - داگرتنی فایلی تاکی PDF یان فایلی دەستەیی پۆل (Batch PDF).

5. **سکانکردنی پێشکەوتوو (Scanning Hub)**
   - **سکان بە کامێرای مۆبایل**: چوارچێوەی ڕێنیشاندەری ڕاستەوخۆ، پشکنینی کوالیتی، ڕووناکی و تەڵخی.
   - **بارکردنی فایل**: بارکردنی وێنە یان فایلی فرەپەڕەیی PDF بە شێوەی دەستەیی (Batch Queue).

6. **ماتۆڕی بینایی کۆمپیوتەر (Computer Vision Engine)**
   - دۆزینەوەی ٤ نیشانەکە لە ٤ گۆشەی پەڕەکە.
   - ڕاستکردنەوەی گۆشە و پەستاندنەوە (Perspective Homography Warping) بۆ سیستەمی ستانداردی ۱۲۰۰ × ۱۷۰۰ پیکسڵ.
   - پێوانەکردنی ناواخنی بازنەکان و جیاکردنەوەی لە چوارچێوەی چاپکراو.
   - پۆلێنکردنی دروست بۆ: هەڵبژێردراو (SELECTED)، بەتاڵ (BLANK)، فرە وەڵام (MULTIPLE)، و گوماناوی (UNCERTAIN).

7. **شاشەی پێداچوونەوەی مامۆستا (Manual Review Screen)**
   - نیشاندانی بڕگەی وێنەی پرسیارە گوماناوییەکان و چاککردن بە یەک کرتە.
   - پاراستنی پێشبینی سەرەتایی ئامێر و تۆمارکردنی کاتی پێداچوونەوە.

8. **ئەنجامەکان و دەرهێنان (Results & Export)**
   - خشتەی گەڕان و فلتەرکردنی ئەنجامەکان.
   - دەرهێنانی فایلەکانی Excel (.xlsx) و CSV بە پیت و هێمای کوردی پارێزراو.

9. **کالیبرەیشن و ڕێکخستنی OMR (Calibration & Diagnostics)**
   - گۆڕینی ئاستی تۆخی بازنەکان و پشکنینی ڕاستەوخۆی پەڕەی نموونە لەگەڵ چینی شیکاری (Debug Overlay).

---

## پێکهاتەی تەکنیکی (Tech Stack)

- **Backend**: Python 3.11, FastAPI, OpenCV (`cv2`), NumPy, ReportLab, pypdfium2, pypdf, SQLite, SQLAlchemy.
- **Frontend**: React 18, Vite, TailwindCSS (RTL Native), Lucide Icons.

---

## دەستپێکردن و کارپێکردن (Running Locally)

### ۱. کارپێکردنی Backend (FastAPI):
```bash
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
- بەڵگەنامەی API: `http://127.0.0.1:8000/api/docs`

### ۲. کارپێکردنی Frontend (Vite / React):
```bash
cd frontend
npm run dev
```
- دەستگەیشتن بە وێبگە: `http://localhost:3000`
